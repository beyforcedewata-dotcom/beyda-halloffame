# 🏆 BEYFORCE DEWATA HALL OF FAME

The official overall standing and tournament match tracker for **Beyforce Dewata** Beyblade X competitions, recording blader achievements across local, regional, and national circuits[cite: 6].

### 🌟 Key Features
- **Overall Leaderboard**: Real-time rankings calculated with a weighted 10-7-5-3 point system for Top 4 podium finishes[cite: 6].
- **Flexible Period Filters**: Filter standings across Full Year, Semesters, Quarters, and Monthly periods[cite: 6].
- **Interactive Player Drawers**: Expandable player profiles featuring podium distribution cards and scrollable match logs[cite: 6].
- **Chronological Match Archives**: Event logs automatically sorted by date to support retroactive/backtrack result entries[cite: 6].
- **Admin Management Panel**: PIN-protected match entry, live editing modal, and event deletion[cite: 6].
- **Firebase Realtime Sync**: Instant data synchronization across clients without page reloads[cite: 6].
- **Data Portability**: One-click CSV and JSON data export for offline backups and spreadsheets[cite: 6].

### 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3 (Modern Responsive Dark Theme), Vanilla JavaScript (ES Modules)[cite: 6]
- **Backend / Database**: Google Firebase Realtime Database[cite: 6]
- **Hosting**: GitHub Pages
